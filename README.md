# Hrithik Gupta — Personal Portfolio

A responsive dark-modern portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Unzip the folder.
2. Open `index.html` in your browser. For best results, use VS Code with the Live Server extension.

## Personalise before publishing
- Replace `assets/profile.jpg` with your own portrait (keep the same filename).
- Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
- Replace the LinkedIn placeholder URL with your actual profile URL.
- Add your resume as `assets/Hrithik_Gupta_Resume.pdf`.
- Add GitHub repository links to each project card after confirming the repositories are public.
- Review dates, skills and project descriptions for accuracy before publishing.

## Publish free
You can deploy this folder using GitHub Pages or drag the folder into a static hosting service such as Netlify.

## Notes
The site intentionally uses an initials fallback until you add your own profile photo. No personal email, phone number, or unverified publication details have been invented.
