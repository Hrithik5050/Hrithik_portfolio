# Hrithik Gupta — Personal Portfolio

A responsive dark-themed personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content and sections
- `style.css` — layout, visual design and responsive styles
- `script.js` — navigation and small interactive behaviours
- `assets/profile.jpg` — add your profile photograph using this exact filename
- `assets/Hrithik_Gupta_Resume.pdf` — add your latest resume using this exact filename

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
Upload the contents of this folder to your GitHub repository and enable **Settings → Pages → Deploy from a branch → main → /(root)**.
